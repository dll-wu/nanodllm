# Reproducing the NanoDLLM paper results

The [numerical companion](companion/) rebuilds all seven numbered figures, thirteen numbered tables and the additional numerical exhibits retained by the manuscript exporters. The calculations start from ten public JSON snapshots and run on CPU with Python 3.11+ and NumPy. The experimental cutoff is November 23, 2026. The display reference is the November 26 manuscript export.

```sh
python -m paper.companion --check
python -m paper.companion --output build/paper-results
```

The first command hashes the inputs, recomputes the statistics and checks every TeX output against the pinned edition in memory. The second also writes 67 TeX files and an unrounded `statistics.json`. Run the commands from the repository root. The numerical path imports neither the trainer nor PyTorch and needs no accelerator, network, tokenizer, corpus or weights. For model execution, the paper implementation lives in `nanodllm.runtime`.

With an existing pdfLaTeX installation including TikZ, booktabs, geometry and natbib, typeset the standalone exhibit collection with two passes for references. The collection keeps the manuscript figure and table numbers, then appends the retained supplementary exhibits.

```sh
cd build/paper-results
pdflatex -no-shell-escape -halt-on-error companion.tex
pdflatex -no-shell-escape -halt-on-error companion.tex
```

## Reductions and uncertainty

**Prediction.** Bits per byte (BPB) pools negative log loss in nats over the scored bytes and divides by ln 2. A common next-token score uses gold left context. Conditional native reconstruction uses the model's trained attention pattern and fixed noise plans. AR causal BPB, full-sequence NELBO and block reconstruction have different targets or estimators. Within-depth TPP charges the parent and child for source positions. It does not measure padded views, dense FLOPs or wall time.

**Components.** Each column of the loss arrays represents the same anonymous document across arms and both seeds. Recompute the within-seed corpus differences and mean them. The 10,000 bootstrap draws use shared document indices across both fits. The original paired and matched-compute comparisons use NumPy's generator. The later full-budget, control-change and shortened-conversion analyses use Python's seeded sampling with replacement. Both use seed 20261106 and percentile endpoints. The historical seed-43/44 table reports the sample SD of two paired differences.

**Block transfer.** Loss arrays retain paired reference/candidate nats, a shared byte denominator and a length stratum. The D4 development and holdout analyses use 2,000 Python draws in first-seen stratum order. D8 and larger development analyses use 5,000 NumPy draws, preserving the respective stratum orders and seeds. The earlier opened 135M/477M sensitivity panel contains only long continuations, the later development panel has 16 short and 16 long documents, and the holdout has 128 of each. The machine label `fresh` on block and component development data means the second, subsequently opened panel. The holdout is a separate sample. The interval conditions on the checkpoints and sampled corruptions. It excludes training-seed population uncertainty and post-selection corrections.

**Tasks.** The primary protocol ranks options by mean-token conditional NELBO and uses gold-length, token-exact completion with full-block masking. Controls use summed ranking loss or sequential masked completion. Each of 21 fixed tasks receives equal weight. The raw mean is the average task accuracy. The centered mean averages (accuracy − baseline) / (1 − baseline). In each joint histogram, `correct` contains four binary outcomes per task, in task order. Both scratch scorers precede both conversion scorers. Scorer order is mean then sum for ranking, full-block then sequential for exact completion. The frequency `items` carries the multiplicity. The [task reduction](companion/tasks.py) makes 10,000 multinomial draws within dataset groups, sharing each draw across the two HellaSwag variants and all scorer controls. This reproduces the conditional paired-item intervals from counts alone. The fixed capped panel comprises 8,845 items per model and covers a subset of CORE.

**Generation.** Reference PPL is exp(summed nats / scored reference tokens). Reference BPB uses summed nats / (scored bytes × ln 2). At 135M/477M the external reference is Gemma 4 31B base. Each setting has 32 prompts × two proposals, with 256 content tokens as the cap. Repeat-4 is the mean repeated-four-gram fraction and EOS counts natural stops before the cap. Tokens/s is the observed mean per-request rate including cache work. The corrected 20M component tables use a frozen 20M AR reference and a geometric mean of seed-level pooled PPLs. The earlier full-sequence generation tables have their own scorers and timing boundaries in their captions. These measures describe predictability, repetition, stopping and speed. Semantic quality and matched-quality speedup require separate evidence.

## Display and release boundaries

The manuscript rounds absolute BPB to three decimals. A nonzero signed difference below 0.001 BPB receives four decimals. If either interval endpoint meets that rule, both endpoints receive four. A dash denotes a missing or untested cell. The grid heatmaps use the displayed three-decimal historical cell values to set the color scale within each family. The 20M decoder repetition ranges use two decimals below one percent and one decimal otherwise. Individual exporters preserve the paper's per-column precision for PPL, throughput, lengths, accuracies and EOS counts.

The public Figure 2 caption corrects the 59M parent lineage. Seeds 50, 51 and 52 used distinct AR parents. Within each seed, the two conversion rates used the same parent. Their checkpoint hashes appear in the [profile catalog](checkpoints.md). This corrects the caption without changing the plotted values or bootstrap calculations. The manifest retains the manuscript-caption file hash alongside the corrected file hash.

Figure 3B retains numerical full-continuation scores and seed ranges. Its prompt and both generation excerpts are omitted. Hash comparisons cover the public figure variant. Apart from the corrected Figure 2 caption and the two redacted Figure 3 files, the manuscript figure and table sources match their reference TeX bytes. The standalone gallery has its own pagination. Reduced snapshots permit reaggregation and conditional interval replay. Historical endpoint averages, recorded timing, authorial scope statements and decoder behavior summaries enter at their retained level of aggregation. Rerunning models, checking the text of individual examples, or measuring end-to-end parent-inclusive compute requires additional evidence.

## Packaging

For standalone use, keep `paper/__init__.py` and the entire `paper/companion/` directory together. The companion reads its manifest, JSON snapshots and TeX templates relative to its own package. To check the numerical reductions and the standalone command from the source checkout, run

```sh
python -m pytest -q tests/test_paper_results*.py
```
